# АПЕКС: сайт стоматологической клиники

Демо-сайт клиники на Astro, сделанный вместе с Claude Code. Клиника, врачи, адрес и реквизиты вымышлены
и помечены в `src/content/site.ts`. Портреты врачей сгенерированы, фото реальных людей не использовались.
Демо закрыто от индексации.

**Демо:** https://dental-studio-ru.pages.dev

## Что внутри

- Два языка: русский `/` и английский `/en/`. Все тексты лежат в одном файле `src/content/site.ts`,
  в разметке текста нет.
- Форма записи отправляет заявку в Telegram через серверную функцию. Токен бота хранится в секретах
  хостинга и в браузер не попадает. От спама защищает скрытое поле-приманка.
- Анимация на GSAP и Lenis, при системной настройке «уменьшить движение» она отключается.
- Разметка schema.org для клиники (на демо выключена вместе с индексацией).
- Нижняя панель на телефоне: звонок и запись в одно касание.

## Найденная ошибка и защита от нее

Блоки при прокрутке появляются из `opacity: 0`, а анимацию двигает `requestAnimationFrame`.
Во встроенных браузерах приложений и в режиме энергосбережения он может стоять, и тогда посетитель
видит пустую страницу. Замер показал 0 кадров в секунду при видимой вкладке.

Поэтому в `src/layouts/Base.astro` есть сторож на `setTimeout`, который в таких условиях продолжает работать.
Если за 1,4 секунды анимация не сделала двух кадров, на страницу вешается класс `motion-dead`
и все блоки сразу показываются в конечном виде.

## Запуск

```bash
npm ci
npm run dev
```

Выкладка на Cloudflare Pages (`functions/api/booking.ts`) или Netlify (`netlify/functions/booking.mts`
вызывает тот же обработчик). Секреты: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`.
